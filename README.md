# Code Battle Arena - Backend Engine

A real-time code execution and performance analytics platform built for competitive programming duels.

## Tech Stack

- Runtime: Bun
- Language: TypeScript
- Framework: Express.js
- Architecture: Clean Architecture
- Monorepo Tool: Turborepo
- Execution Engine: Native C++ (g++) child processes

## Project Architecture

```text
src/
├── config/        # Application and environment settings
├── controllers/   # Request and response handlers
├── middlewares/   # Express middleware
├── models/        # Database schemas
├── repositories/  # Data access layer
├── routes/        # API endpoints
├── services/      # Core business logic
└── types/         # TypeScript definitions
```
